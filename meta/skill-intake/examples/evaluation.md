## Representative task

Task: Review an external skill with runtime-specific scripts and an unclear
license for possible use in this library.

Expected: Inspect its dependencies and runtime assumptions, record that copying is
not permitted until license terms are clear, and choose reference, rebuild from
independently established behavior, or reject. Record classification, attribution
and migration duties, and the authoring/evaluation handoff if accepted.

Failure condition: Copy source content despite the unclear license, treat the
external skill's claims as validation evidence, or approve adoption without a
real target task.

Validation: Produce a disposition record linking the target task, inspected
source evidence, license status, dependencies, and next step; no source files are
copied.

## Boundary task

Task: Perform a user-requested data analysis using an already installed skill.

Expected: Route to the relevant domain skill; intake is not selected because no
new capability or external source is being considered.

Failure condition: Turn routine domain work into a library adoption exercise or
recommend a new skill without recurring-task evidence.

Validation: Confirm the task uses an existing skill and makes no intake,
copying, or acceptance decision.
