## Source of truth

- Skill behavior: `SKILL.md` under `common/`, `personal/`, `meta/`.
- Skill metadata source: skill frontmatter; generated `docs/skill-index.md` + `data/skills.json`.
- Bundles: `data/bundles.json`.
- Promoted set: `data/promoted.json`.
- Installed runtime output: `.agents/skills/`, not `.agent/skills`.
- Safe sync: `python3 scripts/install_skills.py`; `--check` no write; normal sync stops when target exists.
